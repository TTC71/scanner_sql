
# Scanner Produit avec SQLite et Flask

## Fichiers

- `index.html` : Interface web
- `script.js` : Script pour appeler l'API
- `style.css` : (à ajouter selon ton design)
- `server.py` : API Flask
- `produits.db` : Base de données SQLite
- `import_csv.py` : Script pour importer un fichier CSV

## Déploiement

Tu peux héberger `server.py` + `produits.db` sur Render.com :

1. Crée un nouveau service web (Python Flask)
2. Déploie ces fichiers dans le dépôt
3. Modifie `script.js` pour pointer vers l'URL de l'API en ligne (ex: https://mon-api.onrender.com)
